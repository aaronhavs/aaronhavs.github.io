Educational CVT Robot for Haptic Teleoperation

Senior Design Project

Designed and developed an educational robot demonstrating the use of Continuously Variable Transmissions (CVTs) in haptic robotics for teleoperation. A pair of steerable wheels mounted on a rotating cylinder controls the motion of a scissor-lift linkage, allowing the end effector to accurately trace programmable two-dimensional shapes.

  • Designed and implemented a MATLAB feedback control system derived from the system dynamics to accurately position the end effector while maintaining stable behavior for arbitrary user-defined trajectories.
  • Simultaneously computed two independent wheel steering angles using system constraints and inverse kinematics based on the desired end-effector position and scissor-linkage geometry.
  • Derived and tuned controller parameters accounting for hardware limitations, system dynamics, and performance requirements to achieve stable tracking.

Major design challenges: nonlinear system dynamics, determining required wheel/motor positions for desired 2D end-effector coordinates, and integrating sensors to measure desired vs. actual wheel position.

The motion shown here isn't just points moving along an axis for illustration — each dot represents an actual wheel, and its steering angle is computed in real time by the control system from the robot's real equations of motion.

  • Inverse Kinematics

Autonomous Nonholonomic Mobile Robot

LiDAR-Based Path Planning & Navigation

Designed and implemented autonomous navigation software for a nonholonomic mobile robot using LiDAR-based mapping, path planning, and Pure Pursuit control — programming an RC vehicle to navigate between user-defined goal points while avoiding static obstacles.

  • Implemented a breadth-first search path-planning algorithm with a goal-oriented heuristic to generate collision-free paths from mapped LiDAR data.
  • Developed Pure Pursuit steering logic and integrated perception with autonomous navigation.
  • Integrated and validated autonomous waypoint navigation and obstacle avoidance through real-world testing, enabling reliable navigation without operator intervention.
  • LiDAR
  • Path Planning
  • Pure Pursuit
  • Autonomous Navigation

Ball-and-Beam Feedback Control System

Nonlinear Dynamic Control Simulator

Developed a MATLAB and Simulink simulation of a nonlinear ball-and-beam system to model, analyze, and validate feedback controller performance. A feedback controller autonomously adjusted the beam's tilt to stabilize the ball at user-defined reference positions.

  • Derived the nonlinear equations of motion for the ball-and-beam system and built the controller.
  • Used root locus analysis to tune proportional and derivative gains, demonstrating the relationship between closed-loop pole locations and transient system response.
  • Verified controller stability by comparing open- and closed-loop responses and analyzing transient performance through simulation and animation.
  • MATLAB
  • Simulink
  • Root Locus
  • PD Control
